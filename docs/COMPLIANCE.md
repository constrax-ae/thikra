# الأمان والامتثال: ما هو موجود وما ليس موجوداً (2026-10-21)

مسوّدة تقنية، **ليست رأياً قانونياً**. تحتاج مراجعة محامٍ (حماية البيانات الإماراتي PDPL والخليجي، الشروط، الخصوصية) قبل الإطلاق للجمهور.

## للفريق (لوحة الإشراف)
| الضابط | الحالة |
|---|---|
| أدوار (مالك/إشراف/دعم) بمصفوفة صلاحيات مختبرة | ✅ |
| رمز سري (PIN) إلزامي للإدارة في الإنتاج | ✅ |
| **تطبيق مصادقة (TOTP، RFC 6238)**: بعد تفعيله، كل جلسة جديدة تُقفل حتى رمز صالح، ويبقى 30 دقيقة؛ الرمز يُستعمل مرة واحدة؛ إيقافه يحتاج رمزاً | ✅ مختبَر على متجه المعيار نفسه |
| فرض التطبيق على كل الفريق | ✅ عبر `THIKRA_ADMIN_REQUIRE_TOTP=1` (غير مفعّل افتراضياً) |
| قائمة جلسات الفريق وإنهاؤها (المالك) | ✅ |
| سجل تدقيق لا يُعدَّل ولا يُحذف + تنزيله CSV (مع تعطيل الصيغ) وتسجيل التنزيل نفسه | ✅ |
| قائمة عناوين IP مسموحة | ✅ `THIKRA_ADMIN_IPS` (اختيارية) |
| **موافقة مزدوجة** (شخصان) للإجراءات الخطرة | ⬜ **غير منفَّذة عمداً**: المنصة يديرها شخص واحد. تُبنى حين يوجد مالكان |
| تدوير/إبطال مفاتيح التطبيق (API) | ⬜ |
| سياسة احتفاظ بسجل التدقيق | 🟡 يُحفظ كله حالياً (لا يُحذف)؛ المدة تقررها المراجعة القانونية |

## للأشخاص (حقوقهم في بياناتهم)
| الحق | الحالة |
|---|---|
| تصدير بياناتي بنفسي فوراً (JSON + ملفاتي) | ✅ «أنت ← الحساب» |
| حذف حسابي بنفسي فوراً | ✅ (يُرفض إن كنت مالك عائلة: انقل الملكية أولاً) |
| **طلب رسمي للفريق** (نسخة أو محو) بموعد **30 يوماً** | ✅ «أنت ← حقوقي في بياناتي»؛ يظهر للفريق مع إنذار التأخير في «اليوم»، والرد مسجَّل في التدقيق |
| طلب شخص ليس لديه دخول (فقد رقمه) | ⬜ يحتاج مسار تحقق هوية خارج التطبيق |
| قبول الشروط بنسخة مسجَّلة | ✅ إعلان «يحتاج موافقة» يسجل من وافق ومتى |
| إخطار الخرق (Breach) | 🟡 إجراء مكتوب في `RUNBOOKS.md`؛ لا أداة إخطار جماعي مخصصة (الإعلانات والـPush تؤدي الغرض) |

## ما يلزم من المالك
مراجعة قانونية · تحديد مدة احتفاظ التدقيق · مسؤول حماية بيانات (DPO) إن لزم · تفعيل التطبيق للمالك الآن (أنت ← لوحة الإشراف ← الأمان).
