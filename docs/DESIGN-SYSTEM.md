# نظام التصميم (F-09) — الرموز وإمكانية الوصول

**الحالة:** رموز وإمكانية وصول مثبتة باختبار. **ليس نظام تصميم مكتملاً**: مكوّناته من تصميم مصمم محترف وقرار لوحة الألوان ما زالا ينتظران (انظر آخر الوثيقة).

## الرموز (`web/src/styles.css`)
| الرمز | القيمة | الاستعمال |
|---|---|---|
| `ink` | `#1d2a25` | النص الأساسي |
| `muted` | `#55615b` | النص الثانوي (الأوقات، الشروح، الشارات) |
| `paper` / `card` / `line` | `#faf6ee` / `#ffffff` / `#e6dfd0` | الخلفية، البطاقة، الخطوط |
| `green` / `green-soft` | `#1f4d3f` / `#e3eee9` | العلامة والأزرار، وخلفية الشارات |
| `gold` | `#c79a3b` | **تعبئة وقلب الشعار فقط، لا نص** |
| `gold-dark` | `#7a5a13` | نص الذهبي (شارات الوكيل، التنبيهات، المؤسس) |
| `danger` / `danger-soft` | `#b91c1c` / `#fef2f2` | الخطر والحذف |
| `radius-control` / `radius-card` / `text-caption` | 0.75rem / 1rem / 0.6875rem | الاستدارة وحجم الشرح |

اللون أولوية متأخرة بقرار المالك: تغيير أي رمز هنا يعيد فحص التباين تلقائياً (أدناه).

## إمكانية الوصول
- **التباين WCAG AA (4.5:1)** لكل زوج نص/خلفية مستعمل فعلاً (19 زوجاً)، يُقرأ من الأوراق الأنماط الفعلية ويُفحص في `web/contrast.test.ts` ضمن `pnpm test` وCI. **وجد الفحص إخفاقاً حقيقياً:** النص الثانوي كان `ink` بشفافية 50–60% بتباين 3.0–4.1، وهو ما استُبدل بـ`muted` الصلب (≥ 4.9 على كل الخلفيات)، والنص الذهبي بـ`gold-dark`. والاختبار يمنع عودة `text-ink/NN` و`text-gold`.
- **تكبير الخط:** زر «A» في الترويسة يدور بين عادي / كبير (125%) / كبير جداً (150%) ويُحفظ على الجهاز. كل المقاسات rem فتتكبّر الواجهة كلها.
- **اتجاه RTL:** الواجهة بالعربية RTL افتراضياً وتتبع لغة الجهاز؛ تُستعمل خصائص منطقية (`ms-`, `me-`, `start/end`) لا يمين/يسار.

## ما لم يُنجز (صراحةً)
- **مكتبة مكوّنات مصمَّمة** (أزرار، حقول، قوائم، فقاعات) بحالاتها كلها: تحتاج مصمماً.
- **لوحة الألوان النهائية والخط:** قرار المالك مؤجَّل («ممكن تغير اللون لكن هذا غير مهم الآن»).
- ~~الوضع الداكن~~ ✅ منجز: «حسب الجهاز/فاتح/داكن» في «أنت ← المظهر»، رموز مفصولة للنص (`green`) وللتعبئة (`brand`) كي تنقلب النصوص وتبقى الأزرار بنصها الأبيض؛ **التباين AA مفحوص آلياً للثيمين**. وما بقي: فحص قارئ الشاشة اليدوي على جهاز حقيقي، وفحص التباين للصور والأيقونات.
- نسخة الجوال: ستعيد استعمال الرموز نفسها من `@thikra/core` أو ملف رموز مشترك حين يُحسم الإطار.
