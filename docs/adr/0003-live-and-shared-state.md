# ADR 0003: البث الحي والحالة المشتركة (D3)

**الحالة:** الواجهات منفَّذة، وتنفيذ Redis ينتظر خدمة.
**القرار:** `server/state.ts` يحدد `RateLimiter` و`KeyValue` و`Bus`؛ التنفيذ الحالي في الذاكرة. `createLive(bus)` يوصل أحداث العقدة إلى مقابس العقد الأخرى عبر الناقل. Redis لاحقاً يمرّ على **اختبارات العقد نفسها**.
**ما لم يُنفَّذ:** Redis الفعلي، وحضور المستخدم بين العقد (`isVisible` لكل عقدة)، والمقاييس لكل عقدة عمداً.
