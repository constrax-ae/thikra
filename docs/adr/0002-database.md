# ADR 0002: قاعدة البيانات (D2)

**الحالة:** مقترَح (التنفيذ ينتظر حساب سحابة).
**السياق:** SQLite في ملف واحد تكفي للتجربة والعائلات القليلة، لا لخوادم متعددة.
**القرار المقترح:** PostgreSQL مُدارة للإنتاج، مع الهجرات المرقّمة الموجودة (`server/migrations/`) كأساس، وتقسيم منطقي لاحقاً بـ`circle_id`. SQLite تبقى للتطوير والاختبار خلف الواجهة `Db`.
**اليوم:** الواجهة `Db` وهجرات 0001–0007 جاهزة، والاختبارات تعمل على نسختين من SQLite. **لم يُنفَّذ:** مشغّل Postgres ولا أداة نقل بيانات. اختبارات التوافق على النوعين ستُكتب مع التنفيذ.
