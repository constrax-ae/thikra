# ADR 0006: نموذج الذكاء الاصطناعي (D6)

**الحالة:** مقترَح، بانتظار اختيار المزوّد وسقف التكلفة.
**القرار المقترح:** نموذج مستضاف عبر طبقة تجريد تسمح بتبديل المزوّد، مع **سقف تكلفة صارم لكل دائرة**. القواعد اللغوية الحالية تبقى «بوابة أولى» رخيصة تُقلّل استدعاءات النموذج، والنموذج يؤكد قبل أي إجراء حساس، وكل استنتاج حساس (الوفاة، فتح خطاب) يبقى بتأكيد بشري كما اليوم (أدلة وانتظار 3 أيام).
**اليوم:** لا نموذج مضاف؛ الوكيل قواعد فقط (`core/`)، ومفتاح `agent_enabled` في الإدارة يوقفه كلياً.
