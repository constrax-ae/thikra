# ADR 0005: تطبيق الجوال (D5)

**الحالة:** مقرَّر من المالك: React Native.
**القرار:** تطبيق واحد لأندرويد وiOS، مع المنطق المشترك في `core/` (الموجود: تحليل واتساب، خطة الألبوم، القواعد). تخزين محلي مشفّر للعمل بلا اتصال، والمزامنة بالمراجعة `rev` كما اليوم.
**يلزم من المالك:** حساب مطوّر آبل وجوجل، وجهاز أندرويد أو محاكي، ومزوّد SMS حقيقي. **بدأ البناء:** `mobile/` (Expo) نسخة مبكرة بالدخول وقائمة المحادثات ومحادثة نصية، لم تُشغَّل على جهاز بعد (انظر `mobile/README.md`).
