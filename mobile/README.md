# ذكرى للجوال (Expo / React Native)

نسخة **مبكرة**: تسجيل الدخول برقم الهاتف، قائمة المحادثات (الدوائر العائلية في الأعلى)، ومحادثة نصية. تستعمل الخادم نفسه (`/api`) والجلسة محفوظة في التخزين الآمن للجهاز.

**ما فُحص:** الأنواع نظيفة (`npx tsc --noEmit`)، وحزمة أندرويد تُبنى (`npx expo export --platform android`)، وتسلسل الدخول وإرسال رسالة وقراءتها عبر الخادم بالطريقة نفسها التي يستعملها التطبيق (كوكي يدوي). **ما لم يُفحص:** لم يُشغَّل على جهاز ولا محاكي (لا يوجد هنا)، فالتخطيط والخطوط واتجاه RTL على الجهاز غير مُجرَّبة.

**الدعوة من جهات الاتصال:** زر 👥 في المحادثة يفتح منتقي جهات الاتصال الخاص بالنظام (التطبيق لا يقرأ دفتر العناوين ولا يرفع شيئاً)، وما تختاره يفتح رسالة SMS أو واتساب فيها رابط الدعوة. فُحصت الأنواع وبُنيت الحزمة، **ولم تُجرَّب على جهاز** (المنتقي لا يعمل إلا على هاتف).

**الصور والصوت:** تظهر الصور (مع تعليقها) في المحادثة، وزر 📎 يرسل صورة من الاستوديو، والرسائل الصوتية تُشغَّل بالضغط. فُحص عرض الصورة والإرسال في وضع المتصفح (صورة رُفعت وظهرت)، **أما تشغيل الصوت والمنتقي على الهاتف فلم يُجرَّبا** (يحتاجان جهازاً).

**البث الحي:** الرسائل الجديدة وقائمة المحادثات تتحدّث فوراً عبر WebSocket (نفس بوابة الويب)، والاستعلام البطيء (15–20 ثانية) شبكة أمان إن انقطع. جُرّب في وضع المتصفح: رسالة أُرسلت من شخص آخر ظهرت في قائمة المحادثات خلال ثانيتين. **على الهاتف** يُمرَّر الكوكي في ترويسة الاتصال (مدعوم في React Native) ولم يُجرَّب على جهاز.

**ما ينقص:** الرمز السري الثنائي، تسجيل الصوت (التشغيل موجود)، الألبومات والأرشيف، الإشعارات الأصلية، تخزين محلي للعمل بلا اتصال، الأيقونة النهائية.

## التشغيل
```bash
cd mobile
npm install
EXPO_PUBLIC_API_URL=https://عنوان-الخادم npx expo start   # بلا متغير: خادم الديمو
```
افتح التطبيق بـExpo Go على الهاتف (مسح الرمز). للنشر على المتجرين: حساب مطوّر آبل (99$/سنة) وجوجل (25$)، ثم `eas build` (يحتاج حساب Expo).

المجلد مستقل عن مساحة عمل pnpm: لا يؤثر على الخادم ولا الويب ولا CI.
